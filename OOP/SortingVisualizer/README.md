# Sorting Algorithm Visualizer

A Java Swing-based desktop application that visualizes sorting algorithms through animated bars. This project helps students understand how sorting algorithms work and compare their performance.

## Features

- **Four Sorting Algorithms:** Bubble Sort, Selection Sort, Merge Sort, and Quick Sort.
- **Real-Time Visualization:** Watch elements move into sorted order.
- **Adjustable Array Size:** Generate arrays with different numbers of elements.
- **Speed Control:** Adjust the animation speed.
- **Sorting Controls:** Start, pause/resume, and reset the visualization.
- **Performance Metrics:** Track comparisons and swaps or writes.
- **Complexity Information:** View the time complexity of each algorithm.
- **Interactive GUI:** Built using Java Swing.

## Technologies Used

- Java
- Java Swing
- Abstract Window Toolkit (AWT)

## Algorithms and Time Complexity

| Algorithm | Best Case | Average Case | Worst Case |
|---|---|---|---|
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Selection Sort | O(n²) | O(n²) | O(n²) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) |

*Note: Bubble Sort achieves O(n) best-case time when the implementation detects an already sorted array.*

## How to Run

**1. Clone the repository**

```bash

```

**2. Navigate to the project folder**

```bash
cd college-projects/OOP/SortingVisualizer
```

**3. Compile the Java program**

```bash
javac SortingVisualizer.java
```

**4. Run the application**

```bash
java SortingVisualizer
```
