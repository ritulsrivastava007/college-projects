### 🧩 Object-Oriented Programming (OOP)

#### Sudoku Game

A console-based Sudoku game built in Java to practise object-oriented programming, two-dimensional arrays, and validation logic.

**Features:**

* 9×9 Sudoku board with 3×3 sections

* Validation of rows, columns, and 3×3 boxes

* Protection for the original puzzle clues

* Three-wrong-attempt limit

* Console-based input and gameplay

* **Technologies:** Java

* **Folder:** [`OOP/Sudoku`](./OOP/Sudoku)
